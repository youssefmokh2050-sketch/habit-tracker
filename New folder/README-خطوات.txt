بناء تطبيق أندرويد (APK) مجاناً – متتبع العادات

التطبيق هنا مغلّف بأداة Capacitor، يعني بيفتح في نافذة خاصة بيه من غير Chrome، والداتا بتتحفظ جوه التطبيق.

الخطوات (تقدر تعملها كلها من المتصفح):
1) أنشئ حساب مجاني على github.com.
2) اعمل مستودع جديد (New repository). سمّيه أي اسم، واختار Public (مجاني بدون حد)، وفعّل Add a README.
3) ارفع محتويات هذا المجلد: Add file > Upload files، واسحب كل الملفات (www, assets, package.json, capacitor.config.json, .gitignore) ثم Commit.
4) مهم: مجلد .github مخفي على بعض الأجهزة، فلو ما ظهرش عندك، اعمله يدوياً:
   Add file > Create new file، واكتب الاسم بالظبط:  .github/workflows/build-apk.yml
   وانسخ جواه محتوى الملف الموجود في المجلد، ثم Commit.
5) افتح تبويب Actions. هتلاقي "Build APK" شغّال (أو اضغط Run workflow). استنى 5-10 دقايق لحد علامة ✓ خضراء.
6) افتح التشغيل الناجح، وانزل لقسم Artifacts ونزّل habit-tracker-apk (ملف zip).
7) فك الضغط، وهتلاقي app-debug.apk. افتحه على موبايلك واسمح بالتثبيت من مصادر غير معروفة، ثم ثبّته.

ملاحظات:
- المستودع Public بيظهر كود التطبيق فقط، مش بياناتك. بياناتك على موبايلك.
- الملف ده نسخة Debug بتتثبت مباشرة. النشر على Google Play محتاج توقيع Release وحساب مطوّر (مش مشمول هنا).
- لتعديل التطبيق لاحقاً: عدّل www/index.html في المستودع، وGitHub يعيد البناء تلقائياً.
- لو فشل البناء، افتح التشغيل الفاشل وانسخ رسالة الخطأ وابعتها لي.
